# 标注+三元组拆分实现文档

## 一、整体思路

本脚本实现了一个高效的知识图谱标注 pipeline：
1. **读取原始数据**（CSV 格式）
2. **调用阿里云 API** 进行三元组标注
3. **实时写入 MySQL 数据库**，同时完成**标注内容和三元组拆分**两条写入

核心设计理念：**一次 API 调用，同时产出两条数据**
- `annotations` 表：存储完整的标注结果（原始标注格式）
- `triples` 表：存储拆分后的结构化三元组（entity1-relation-entity2）

---

## 二、数据库表结构

### 2.1 annotations 表（标注主表）

```sql
CREATE TABLE IF NOT EXISTS annotations (
    id INT AUTO_INCREMENT PRIMARY KEY,
    num INT NOT NULL,          -- 对应原始数据的 id
    content TEXT,               -- 原始新闻内容
    keyword VARCHAR(500),       -- 关键词
    labeled TEXT,              -- 标注结果（带标签的文本）
    status VARCHAR(20) DEFAULT 'pending',  -- 状态：pending/done
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_num (num)
)
```

### 2.2 triples 表（三元组子表）

```sql
CREATE TABLE IF NOT EXISTS triples (
    id INT AUTO_INCREMENT PRIMARY KEY,
    num INT NOT NULL,          -- 对应 annotations.num，关联用
    entity1 VARCHAR(500),      -- 头实体
    relation VARCHAR(500),     -- 关系
    entity2 VARCHAR(500),      -- 尾实体
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_num (num)
)
```

## 三、三元组拆分实现

### 3.1 标注格式约定

采用 XML 风格的标签格式：

| 标签 | 含义 |
|------|------|
| `<js>...</js>` | 头实体 |
| `<R>...</R>` | 关系 |
| `<cp>...</cp>` | 尾实体 |

实体类型嵌套示例：
- `<js><gs>公司</gs></js>` - 公司类型的头实体
- `<js><rw>人物</rw></js>` - 人物类型的头实体
- `<cp><sb>产品</sb></cp>` - 产品类型的尾实体

### 3.2 拆分逻辑（parse_triples 函数）

核心代码位于 `parse_triples` 函数（第 117-154 行）：

```python
def parse_triples(labeled_text):
    """解析标注内容，提取三元组（一个数据可能拆分成多个）"""
    if not labeled_text or labeled_text.strip() == "" or labeled_text == "无":
        return []

    triples = []

    # 步骤1：用中文分号分隔多个三元组
    parts = re.split(r'[；;\n]', labeled_text)

    for part in parts:
        if not part.strip():
            continue

        # 步骤2：提取头实体（尝试多种标签）
        entity1 = None
        for tag in ['js', 'gs', 'ly', 'yw', 'jg', 'rw', 'dd', 'xm']:
            match = re.search(rf'<{tag}>(.*?)</{tag}>', part)
            if match:
                entity1 = match.group(1).strip()
                break

        # 步骤3：提取关系
        relation_match = re.search(r'<R>(.*?)</R>', part)
        relation = relation_match.group(1).strip() if relation_match else None

        # 步骤4：提取尾实体
        entity2_match = re.search(r'<cp>(.*?)</cp>', part)
        entity2 = entity2_match.group(1).strip() if entity2_match else None

        # 步骤5：有效三元组才添加
        if entity1 and relation and entity2:
            triples.append({
                "entity1": entity1,
                "relation": relation,
                "entity2": entity2
            })

    return triples
```

### 3.3 拆分流程图

```
原始标注文本（可能包含多个三元组）
            │
            ▼
┌─────────────────────────────┐
│ 用分号(；或;)分割成多个部分   │
└─────────────────────────────┘
            │
            ▼
┌─────────────────────────────┐
│ 遍历每个部分                │
│  ├─ 提取 <js>...</js> 头实体 │
│  ├─ 提取 <R>...</R> 关系    │
│  └─ 提取 <cp>...</cp> 尾实体 │
└─────────────────────────────┘
            │
            ▼
┌─────────────────────────────┐
│ 验证三元要素完整，生成字典   │
└─────────────────────────────┘
            │
            ▼
       返回三元组列表
```

## 四、数据写入实现

### 4.1 save_to_db 函数（第 178-210 行）

```python
def save_to_db(num, content, keyword, labeled):
    """保存标注结果到数据库"""
    conn = get_db_connection()
    cursor = conn.cursor()

    try:
        # 1. 插入或更新标注数据
        cursor.execute("""
            INSERT INTO annotations (num, content, keyword, labeled, status)
            VALUES (%s, %s, %s, %s, 'done')
            ON DUPLICATE KEY UPDATE
                labeled = VALUES(labeled), keyword = VALUES(keyword), status = 'done'
        """, (num, content, keyword, labeled))

        # 2. 解析三元组
        triples = parse_triples(labeled)

        # 3. 先删除该 num 的旧三元组（避免重复）
        cursor.execute("DELETE FROM triples WHERE num = %s", (num,))

        # 4. 插入新的三元组
        for t in triples:
            cursor.execute("""
                INSERT INTO triples (num, entity1, relation, entity2)
                VALUES (%s, %s, %s, %s)
            """, (num, t["entity1"], t["relation"], t["entity2"]))

        conn.commit()
    except Exception as e:
        print(f"数据库错误: {e}")
        conn.rollback()
    finally:
        conn.close()
```

### 4.2 写入特点

- **原子操作**：标注和三元组在同一个事务中提交
- **先删后插**：每次更新时先删除旧三元组，保证数据一致性
- **实时写入**：API 调用完成后立即写入，而非批量处理

## 五、联表查询 SQL

### 5.1 标注 + 三元组联查

```sql
-- 按 num 和三元组 id 顺序显示
SELECT 
    a.num,
    a.content,
    a.keyword,
    a.labeled,
    t.entity1,
    t.relation,
    t.entity2
FROM annotations a
INNER JOIN triples t ON a.num = t.num
WHERE a.status = 'done'
ORDER BY a.num, t.id;
```

### 5.2 只导出标注（不拆分）

```sql
SELECT 
    num,
    content,
    keyword,
    labeled
FROM annotations
WHERE status = 'done'
ORDER BY num;
```

### 5.3 统计查询

```sql
-- 已标注总数
SELECT COUNT(*) FROM annotations WHERE status = 'done';

-- 三元组总数
SELECT COUNT(*) FROM triples;
```

## 八、注意事项

1. **编码问题**：Windows 环境下需设置 `chcp 65001` 保证中文正常显示
2. **API 账户**：需确保阿里云账户余额充足，欠费会返回 `[账户欠费]`
3. **并发控制**：并发数不宜过高，建议 5-10，避免 API 限流
4. **分号分隔**：标注结果用中文分号 `；` 或英文分号 `;` 分隔多个三元组
