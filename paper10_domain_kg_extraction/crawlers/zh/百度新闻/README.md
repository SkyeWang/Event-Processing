# 百度新闻爬虫系统使用说明

## 📋 项目概述

这是一个基于Flask和Selenium的新闻爬虫系统，支持Twitter和百度新闻两种数据源的爬取，具备实时数据流式传输、可视化展示和强大的反检测能力。

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install flask selenium beautifulsoup4 openpyxl requests pandas lxml webdriver-manager
```

### 2. 下载ChromeDriver

确保ChromeDriver版本与Chrome浏览器版本匹配，并添加到系统PATH。

### 3. 启动应用

```bash
python app.py
```

访问 http://127.0.0.1:5000

## 🎯 功能特性

### 数据源支持
- **Twitter爬虫**: 需要登录账号，支持日期范围搜索
- **百度新闻爬虫**: 无需登录，支持关键词搜索和数量限制

### 核心功能
- **实时流式传输**: 使用SSE技术实时推送爬取数据
- **数据可视化**: DataTables表格展示 + Chart.js图表分析
- **智能反检测**: 随机延迟、鼠标模拟、User-Agent轮换
- **验证码处理**: 自动检测并暂停等待人工处理
- **停止控制**: 可随时停止正在运行的爬虫
- **数据管理**: 支持清除历史数据

## 📊 数据字段

## 🛠️ 使用方法

### 数据清洗功能

1. **准备数据**: 将需要清洗的CSV文件放入`data/`目录
2. **运行清洗工具**:
   ```bash
   python clean_data.py
   ```
3. **功能说明**:
   - 自动去除无效数据（内容提取失败的记录）
   - 按句子分割内容（以'。''！''？''......'为分割点）
   - 生成包含`num`、`content`、`keyword`三个字段的清洗后文件
   - 所有文件处理结果合并到`cleaned_data/all_cleaned_data.csv`

### 百度新闻爬虫

1. **选择数据源**: 点击"百度新闻爬虫"选项
2. **设置参数**:
   - 关键词：支持多个关键词，逗号分隔
   - 最大爬取数量：设置爬取上限
   - 清除原有数据：是否删除之前的CSV文件
3. **开始爬取**: 点击"开始爬取"按钮
4. **监控进度**: 实时查看爬取数据和统计图表
5. **停止爬取**: 如需停止，点击"停止爬虫"按钮

### Twitter爬虫

1. **选择数据源**: 点击"Twitter爬虫"选项
2. **设置参数**:
   - 关键词：支持多个关键词，逗号分隔
   - 日期范围：设置开始和结束日期
   - 账号信息：输入Twitter用户名和密码
3. **开始爬取**: 点击"开始爬取"按钮

## ⚙️ 配置说明

### 反检测设置
- 每30条数据休息15-30秒随机时间
- 随机鼠标移动模拟人类行为
- 多种User-Agent轮换使用

- 自动去重机制避免重复数据

## 🔧 故障排除

### 常见问题

1. **ChromeDriver版本不匹配**
   - 确保ChromeDriver版本与Chrome浏览器版本一致
   - 下载地址：https://chromedriver.chromium.org/

2. **验证码问题**
   - 系统会自动检测验证码并弹出提示
   - 在浏览器中手动完成验证后点击"继续爬取"

3. **爬取速度慢**
   - 这是正常现象，系统设计了智能延迟避免被封
   - 可以在代码中调整延迟时间

4. **数据为空**
   - 检查关键词是否正确
   - 确认网络连接正常
   - 查看控制台错误信息

## 📝 注意事项

1. **合规使用**: 请遵守相关网站的robots.txt和使用条款
2. **频率控制**: 避免过于频繁的请求导致IP被封
3. **数据备份**: 定期备份重要数据
4. **资源占用**: 爬虫运行时会占用较多CPU和内存资源
