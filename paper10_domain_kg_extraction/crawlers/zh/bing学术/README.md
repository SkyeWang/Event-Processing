# Bing学术搜索爬虫

基于Edge浏览器的Bing学术搜索爬虫程序，用于批量爬取中文关键词相关的学术文献信息。

## 功能特点

- 🔍 **智能关键词管理**: 自动读取keywords文件夹中的txt文件，支持断点续爬
- 🚫 **URL去重**: 自动过滤重复URL，避免重复爬取
- 🤖 **反检测机制**: 随机User-Agent、鼠标移动模拟、自动化特征隐藏
- 📊 **数据保存**: CSV格式保存，包含标题、URL、正文内容
- ⏱️ **智能延迟**: 随机延迟20-30秒，避免请求过快
- 📝 **进度保留**: 完成的关键词自动移动到keywords_fin文件夹

## 安装依赖

```bash
pip install -r requirements.txt
```

## 目录结构

```
BCI/
├── bing_academic_crawler.py  # 主爬虫程序
├── requirements.txt          # 依赖文件
├── keywords/                 # 关键词文件夹
│   ├── 脑机接口.txt
│   └── 第六代移动通讯.txt
├── keywords_fin/             # 已完成关键词文件夹
├── data/                     # 数据保存文件夹
└── crawler.log              # 日志文件
```

## 使用方法

1. **准备关键词文件**: 将关键词按行写入txt文件，放在keywords文件夹中
2. **运行爬虫**: 
   ```bash
   python bing_academic_crawler.py
   ```
3. **查看结果**: 爬取的数据保存在data文件夹中，按关键词分别保存

## 程序特性

### 浏览器配置
- 使用Edge浏览器
- 随机User-Agent
- 隐藏自动化特征
- 模拟鼠标移动

### 爬取流程
1. 读取keywords文件夹中的txt文件
2. 依次处理每个关键词
3. 搜索Bing学术页面
4. 提取搜索结果
5. 获取详细内容
6. 保存到CSV文件
7. 移动已完成关键词到keywords_fin

### 数据处理
- 自动识别PDF、视频等非文本内容
- URL去重机制
- 内容长度限制（30000字符）
- 错误处理和日志记录

## 注意事项

1. **浏览器驱动**: 确保已安装Edge浏览器和对应版本的WebDriver
2. **网络环境**: 稳定的网络连接，避免频繁超时
3. **存储空间**: 大量数据爬取需要足够的磁盘空间
4. **合规使用**: 请遵守网站robots.txt和相关法律法规

## 日志文件

程序运行时会生成`crawler.log`文件，记录详细的运行信息和错误信息，便于调试和监控。

## 故障排除

1. **浏览器驱动问题**: 检查Edge浏览器版本是否匹配
2. **网络超时**: 调整timeout参数或检查网络连接
3. **内存不足**: 适当减少并发数或增加系统内存
